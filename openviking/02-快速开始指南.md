## 1. 环境准备

### 1.1 系统要求

参考项目根目录 `README.md` "Prerequisites"：

| 要求 | 最低版本 | 备注 |
|------|----------|------|
| Python | 3.10+ | 主开发语言 |
| Go | 1.22+ | 仅在**从源码构建 AGFS（Go 实现）**时需要；pip 安装预编译包不需要 |
| C++ 编译器 | GCC 9+ / Clang 11+（C++17）| 仅在重新编译核心扩展（`src/`）时需要 |
| 操作系统 | Linux / macOS / Windows | — |
| 网络 | 访问模型服务 | 火山引擎/OpenAI 等 |

### 1.2 检查 Python 版本

```bash
python --version
# 确保输出 >= Python 3.10
```

## 2. 安装 OpenViking

### 2.1 使用 pip 安装

```bash
pip install openviking --upgrade --force-reinstall
```

> 安装后会注册三个 console scripts（来自 `pyproject.toml`）：
> - `openviking-server` —— HTTP 服务入口（也提供 `init` / `doctor` 子命令）
> - `openviking` / `ov` —— Rust CLI 包装器
> - `vikingbot` —— 可选的 Bot 网关

### 2.2 验证安装

```bash
python -c "import openviking; print(openviking.__version__)"
openviking-server --version
```

### 2.3 一键交互式初始化（推荐）

`openviking-server init` 会引导你完成模型选择、Codex/Kimi/GLM 登录、Ollama 自动安装、`ov.conf` 生成等所有步骤；`doctor` 用于校验本地配置：

```bash
openviking-server init      # 交互式向导
openviking-server doctor    # 校验配置是否可用
```

## 3. 配置模型服务

### 3.1 创建配置文件

```bash
mkdir -p ~/.openviking
touch ~/.openviking/ov.conf
```

### 3.2 配置火山引擎（推荐）

参考 README.md 中的官方示例，编辑 `~/.openviking/ov.conf`：

```json
{
  "storage": {
    "workspace": "/home/your-name/openviking_workspace"
  },
  "embedding": {
    "dense": {
      "api_base": "https://ark.cn-beijing.volces.com/api/v3",
      "api_key": "YOUR_VOLCENGINE_API_KEY",
      "provider": "volcengine",
      "dimension": 1024,
      "model": "doubao-embedding-vision-251215"
    },
    "max_concurrent": 10
  },
  "vlm": {
    "api_base": "https://ark.cn-beijing.volces.com/api/v3",
    "api_key": "YOUR_VOLCENGINE_API_KEY",
    "provider": "volcengine",
    "model": "doubao-seed-2-0-pro-260215",
    "max_concurrent": 100
  }
}
```

### 3.3 配置 OpenAI（备选）

```json
{
  "embedding": {
    "dense": {
      "api_base": "https://api.openai.com/v1",
      "api_key": "YOUR_OPENAI_API_KEY",
      "provider": "openai",
      "dimension": 3072,
      "model": "text-embedding-3-large"
    }
  },
  "vlm": {
    "api_base": "https://api.openai.com/v1",
    "api_key": "YOUR_OPENAI_API_KEY",
    "provider": "openai",
    "model": "gpt-4o"
  }
}
```

> 📝 **支持的 provider**（来自 README.md）：
> - **VLM**：`volcengine`、`openai`、`openai-codex`、`kimi`、`glm`（即 z.ai/zhipu）
> - **Embedding**：`volcengine`、`openai`、`jina`、`voyage`、`minimax`、`vikingdb`、`gemini`

## 4. 运行第一个示例

### 4.1 创建示例脚本

创建 `example.py`：

```python
import openviking as ov

client = ov.OpenViking(path="./data")

try:
    client.initialize()
    print("OpenViking 初始化完成")

    add_result = client.add_resource(
        path="https://raw.githubusercontent.com/volcengine/OpenViking/refs/heads/main/README.md",
        wait=True,
    )
    root_uri = add_result["root_uri"]
    print(f"资源 URI: {root_uri}")

    ls_result = client.ls(root_uri)
    print(f"\n目录: {ls_result}")

    glob_result = client.glob(pattern="**/*.md", uri=root_uri)
    if glob_result["matches"]:
        content = client.read(glob_result["matches"][0])
        print(f"找到 {len(glob_result['matches'])} 个文件")
        print(f"内容预览: {content[:200]}...")

    client.wait_processed()

    abstract = client.abstract(root_uri)
    overview = client.overview(root_uri)
    print(f"L0 摘要: {abstract[:100]}...")
    print(f"L1 概览: {overview[:200]}...")

    results = client.find("what is openviking", target_uri=root_uri)
    print(f"\n命中 {results.total} 条结果:")
    for r in results.resources:
        print(f"  - {r.uri} (score={r.score:.4f}, level={r.level})")

finally:
    client.close()
```

### 4.2 运行脚本

```bash
python example.py
```

### 4.3 预期输出（示例）

```
OpenViking 初始化完成
资源 URI: viking://resources/README.md

目录: [...]
找到 1 个文件
内容预览: ...
L0 摘要: OpenViking: ...
L1 概览: # OpenViking ...

命中 3 条结果:
  - viking://resources/README.md (score=0.8523, level=0)
  - viking://resources/README.md (score=0.7891, level=1)
  - viking://resources/README.md (score=0.7654, level=2)
```

> `MatchedContext` 没有 `is_leaf` 字段，只有 `level`（0/1/2，对应 L0/L1/L2，默认 2）。

## 5. 核心操作演示

### 5.1 文件系统操作

```python
import openviking as ov

client = ov.OpenViking(path="./data")
client.initialize()

# 列出目录
result = client.ls("viking://resources/")
print(result)

# 创建目录
client.mkdir("viking://resources/myproject/docs")

# 读取文件
content = client.read("viking://resources/README.md")

# 获取摘要 (L0)
abstract = client.abstract("viking://resources/README.md")

# 获取概览 (L1)
overview = client.overview("viking://resources/README.md")

# 移动/重命名
client.mv("viking://resources/old", "viking://resources/new")

# 删除
client.rm("viking://resources/temp")

client.close()
```

### 5.2 资源管理

```python
# 添加本地文件
result = client.add_resource(path="./docs")
print(result['root_uri'])

# 添加 URL
result = client.add_resource(
    path="https://example.com/docs.pdf"
)
print(result['root_uri'])

# 添加 GitHub 仓库
result = client.add_resource(
    path="https://github.com/user/repo"
)
print(result['root_uri'])

# 等待处理完成
client.wait_processed()
```

### 5.3 语义搜索

```python
# 简单搜索（find）：仅向量召回 + Rerank（如已配置）
results = client.find(
    query="OAuth 认证方法",
    target_uri="viking://resources/docs",
    limit=10,
)
for r in results.resources:
    print(f"{r.uri} (score={r.score:.4f})")

# 复杂搜索（search）：含意图分析、会话上下文、多 TypedQuery
session = client.session()
session.add_message("user", [TextPart(text="帮我创建 RFC 文档")])
results = client.search(
    query="帮我创建 RFC 文档",
    session=session,           # 注意参数名是 session 不是 session_info
)
print(results.query_plan)      # 含意图分析的 reasoning 与 0~5 个 TypedQuery
```

> ⚠️ `client.search()` **没有 `mode` 参数**；THINKING/QUICK 是内部 `RetrieverMode`，仅在调用层透传时使用。是否启用 Rerank 取决于 `ov.conf` 是否配置了 `rerank`。

### 5.4 会话管理

```python
from openviking.message import TextPart, ContextPart

session = client.session(session_id="chat_001")

session.add_message(
    "user",
    [TextPart(text="如何配置 embedding?")],
)

session.add_message(
    "assistant",
    [
        TextPart(text="配置方法如下..."),
        ContextPart(
            uri="viking://resources/config.md",
            context_type="resource",
            abstract="OpenViking 配置指南",
        ),
    ],
)

session.used(contexts=["viking://user/memories/profile.md"])

result = session.commit()  # 归档 + 后台异步提取记忆
print(result["task_id"], result["archive_uri"])
```

## 6. 进阶使用

### 6.1 HTTP 服务模式

**服务端启动**（使用 pyproject 注册的 `openviking-server` 入口，不是 `python -m openviking`）：

```bash
# 默认 host=127.0.0.1, port=1933
openviking-server

# 显式指定
openviking-server --host 0.0.0.0 --port 1933 --config ~/.openviking/ov.conf

# 启动同时拉起 vikingbot 网关
openviking-server --with-bot

# 多 worker
openviking-server --workers 4
```

**客户端连接**：

```python
import openviking as ov

# 同步 HTTP 客户端
client = ov.SyncHTTPClient(
    url="http://localhost:1933",
    api_key="your-api-key",   # 服务端配置 root_api_key 时必填
)
client.initialize()

result = client.find("query", target_uri="viking://resources/")
client.close()
```

### 6.2 异步使用

`AsyncOpenViking` 才是异步客户端；`OpenViking` 默认是同步类：

```python
import asyncio
import openviking as ov

async def main():
    client = ov.AsyncOpenViking(path="./data")
    await client.initialize()

    result = await client.add_resource(path="./docs", wait=True)
    results = await client.find("query")

    await client.close()

asyncio.run(main())
```

> 同样地，HTTP 异步客户端是 `ov.AsyncHTTPClient`（不是 `ov.HTTPClient`）。

### 6.3 启用 Rerank

只需在 `ov.conf` 中追加 `rerank` 段：

```json
{
  "rerank": {
    "api_base": "https://ark.cn-beijing.volces.com/api/v3",
    "api_key": "your-api-key",
    "provider": "volcengine",
    "model": "doubao-seed-rerank"
  }
}
```

启动后，`HierarchicalRetriever` 会自动在 THINKING 模式下使用 Rerank（详见 `openviking/retrieve/hierarchical_retriever.py`）。**没有 `ov.SearchMode` 这个类**。
