## 2. 核心流程

### 2.1 资源添加流程

```mermaid
sequenceDiagram
    participant C as Client
    participant S as Service
    participant P as Parse
    participant VFS as VikingFS
    participant Q as SemanticQueue
    participant VB as VectorDB
    participant M as Model

    C->>S: add_resource(path)
    S->>P: parse(path)
    P->>VFS: create_tree()
    VFS->>Q: enqueue()
    
    Q->>M: generate L0 (async)
    M-->>Q: L0 content
    Q->>VFS: write .abstract.md
    
    Q->>M: generate L1 (async)
    M-->>Q: L1 content
    Q->>VFS: write .overview.md
    
    Q->>VB: index(uri, vector)
    VB-->>Q: confirmed
    
    S-->>C: result {root_uri}
```

### 2.2 检索流程

```mermaid
sequenceDiagram
    participant C as Client
    participant S as SearchService
    participant IA as IntentAnalyzer
    participant HR as HierarchicalRetriever
    participant R as Rerank
    participant VB as VectorDB
    participant VFS as VikingFS
    participant M as Model

    C->>S: find(query, target_uri)
    
    alt search mode
        S->>IA: analyze(query, session)
        IA->>M: LLM intent analysis
        M-->>IA: TypedQuery[]
        IA-->>S: queries
    else find mode
        S->>S: use raw query
    end
    
    S->>HR: retrieve(queries)
    
    loop 层级检索
        HR->>VB: global search
        VB-->>HR: candidate dirs
        HR->>HR: push to priority queue
        
        loop 递归探索
            HR->>HR: pop high score dir
            HR->>VB: search children
            VB-->>HR: child results
            HR->>HR: calculate final score
            HR->>HR: push sub-dirs to queue
        end
    end
    
    HR-->>S: candidates
    
    alt need rerank
        S->>R: rerank(query, candidates)
        R->>M: LLM scoring
        M-->>R: scores
        R-->>S: sorted results
    end
    
    S->>VFS: load L0/L1
    S-->>C: FindResult
```

### 2.3 会话提交流程

```mermaid
sequenceDiagram
    participant C as Client
    participant SeS as SessionService
    participant Msg as Message
    participant Comp as Compressor
    participant ME as MemoryExtractor
    participant VFS as VikingFS
    participant VB as VectorDB
    participant M as Model

    C->>SeS: session.commit()
    SeS->>Msg: get messages
    
    SeS->>Comp: compress(index)
    Comp->>VFS: archive messages
    Comp->>M: generate summary
    M-->>Comp: summary
    Comp->>VFS: write .abstract/.overview
    
    SeS->>ME: extract(messages)
    ME->>M: LLM extraction
    M-->>ME: candidate memories
    
    loop 去重决策
        ME->>VB: vector search
        VB-->>ME: similar memories
        ME->>M: LLM dedup decision
    end
    
    M-->>ME: decisions
    
    loop 处理每个记忆
        alt CREATE
            ME->>VFS: create memory
            ME->>VB: index
        alt UPDATE
            ME->>VFS: update memory
            ME->>VB: update vector
        alt MERGE
            ME->>VFS: merge memories
        end
    end
    
    SeS-->>C: result
```

## 4. 数据流向

### 4.1 写入数据流

```mermaid
flowchart LR
    subgraph Input["输入"]
        PDF[PDF]
        MD[Markdown]
        URL[URL]
        Git[GitHub]
    end

    subgraph Parse["解析"]
        PDF --> P1[PDF Parser]
        MD --> P2[Markdown Parser]
        URL --> P3[URL Parser]
        Git --> P4[Git Parser]
    end

    subgraph Build["树构建"]
        P1 --> TB[TreeBuilder]
        P2 --> TB
        P3 --> TB
        P4 --> TB
    end

    subgraph Store["存储"]
        TB --> AGFS[AGFS]
        AGFS --> Queue[SemanticQueue]
    end

    subgraph Index["索引"]
        Queue --> SP[SemanticProcessor]
        SP --> L0[L0 生成]
        SP --> L1[L1 生成]
        L0 --> VB[VectorDB]
        L1 --> VB
    end
```

### 4.2 读取数据流

```mermaid
flowchart LR
    Query[查询] --> Intent[意图分析]
    
    Intent --> Typed[TypedQuery]
    
    Typed --> Global[全局搜索]
    
    Global --> TopK[Top-K 目录]
    
    TopK --> Queue[优先队列]
    
    Queue --> Loop{递归}
    
    Loop --> Pop[弹出]
    Pop --> Search[搜索子节点]
    Search --> Score[计算分数]
    
    Score --> Filter[阈值过滤]
    Filter --> Collect[收集结果]
    Filter --> Push[子目录入队]
    
    Push --> Loop
    
    Loop --> Done{队列空?}
    Done --> Rerank[Rerank]
    
    Rerank --> Load[加载 L0/L1]
    Load --> Return[返回结果]
```

## 5. 状态机

### 5.1 资源处理状态

```mermaid
stateDiagram-v2
    [*] --> Pending: add_resource()
    Pending --> Processing: 开始解析
    Processing --> Indexed: 索引完成
    Indexed --> Ready: L0/L1 生成完成
    Ready --> [*]
    
    Processing --> Failed: 解析失败
    Failed --> [*]
```

### 5.2 会话状态

```mermaid
stateDiagram-v2
    [*] --> Created: session()
    Created --> Active: add_message()
    Active --> Active: used()
    Active --> Compressing: commit()
    Compressing --> Active: 归档完成
    Compressing --> Extracting: 提取记忆
    Extracting --> Active: 记忆写入
    Active --> Closed: close()
    Closed --> [*]
```

### 5.3 记忆更新状态

```mermaid
stateDiagram-v2
    [*] --> Extracted: 从消息提取
    
    Extracted --> Filtering: 向量预过滤
    Filtering --> Deduplicating: LLM 去重
    
    Deduplicating --> Decision
    Decision --> Creating: CREATE
    Decision --> Updating: UPDATE
    Decision --> Merging: MERGE
    Decision --> Skipping: SKIP
    
    Creating --> Stored: 写入存储
    Updating --> Stored
    Merging --> Stored
    
    Stored --> [*]
    Skipping --> [*]
```
