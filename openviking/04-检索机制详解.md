## 1. 检索概述

### 1.1 检索架构

```mermaid
flowchart TB
    Query[查询] --> Intent[意图分析]
    
    subgraph IntentAnalysis["意图分析"]
        Intent --> Typed[生成 TypedQuery]
    end
    
    Typed --> Hierarchical[层级检索]
    
    subgraph HierarchicalRetriever["层级检索"]
        Hierarchical --> Global[全局向量搜索]
        Global --> Recursive[递归目录探索]
        Recursive --> Score[分数传播]
    end
    
    Score --> Rerank[Rerank 精排]
    
    Rerank --> Result[最终结果]
```

### 1.2 检索流程

```
查询 → 意图分析 → 层级检索 → Rerank → 结果
   ↓          ↓          ↓
TypedQuery  目录递归    精排评分
```

## 2. find vs search

| 特性 | find() | search() |
|------|--------|----------|
| 会话上下文 | 不需要 | 需要 |
| 意图分析 | 不使用 | 使用 LLM 分析 |
| 查询数量 | 单一查询 | 0-5 个 TypedQuery |
| 延迟 | 低 | 较高 |
| 适用场景 | 简单查询 | 复杂任务 |

### 2.1 find() 使用场景

```python
# 简单查询 - 直接使用向量搜索
results = client.find(
    "OAuth 认证",
    target_uri="viking://resources/docs"
)
```

### 2.2 search() 使用场景

```python
# 复杂任务 - 需要意图分析
session = client.session()
results = client.search(
    "帮我创建一个 RFC 文档",
    session_info=session
)
```

## 3. 意图分析

### 3.1 IntentAnalyzer

IntentAnalyzer 使用 LLM 分析查询意图，生成 0-5 个 TypedQuery：

```mermaid
flowchart LR
    subgraph Input["输入"]
        Comp[会话压缩摘要]
        Messages[最近5条消息]
        Query[当前查询]
    end
    
    Input --> LLM[LLM 分析]
    
    subgraph Output["输出 TypedQuery"]
        LLM --> Q[str 重写查询]
        LLM --> Type[context_type]
        LLM --> Intent[intent]
        LLM --> Priority[priority 1-5]
    end
```

### 3.2 TypedQuery 结构

```python
@dataclass
class TypedQuery:
    query: str              # 重写后的查询
    context_type: ContextType  # MEMORY/RESOURCE/SKILL
    intent: str             # 查询目的
    priority: int           # 1-5 优先级
```

### 3.3 查询类型映射

| context_type | 查询风格 | 示例 |
|--------------|----------|------|
| **skill** | 动词开头 | "创建 RFC 文档"、"提取 PDF 表格" |
| **resource** | 名词短语 | "RFC 文档模板"、"API 使用指南" |
| **memory** | "用户XX" | "用户的代码规范偏好" |

### 3.4 特殊情况

- **0 个查询**：闲聊、问候等不需要检索的场景
- **多个查询**：复杂任务可能需要技能 + 资源 + 记忆

```mermaid
flowchart TD
    Query[用户查询] --> Analyze[LLM 分析]
    
    Analyze --> Type{判断类型}
    
    Type -->|闲聊/问候| None[返回空结果]
    Type -->|单一意图| Single[生成1个 TypedQuery]
    Type -->|复杂任务| Multiple[生成多个 TypedQuery]
    
    None --> Done
    Single --> Done
    Multiple --> Done
```

## 4. 层级检索

### 4.1 HierarchicalRetriever

使用优先队列递归搜索目录结构：

```mermaid
flowchart TB
    Start[开始] --> Init[初始化优先队列]
    Init --> Global[全局向量搜索]
    
    Global --> TopK[取 top-k 高分目录]
    TopK --> Queue[加入优先队列]
    
    Loop{队列非空?}
    Queue --> Loop
    
    Loop -->|Yes| Pop[弹出最高分目录]
    Pop --> Search[搜索子节点]
    
    Search --> Calc[计算最终分数]
    Calc --> Score[final_score = 0.5*embedding + 0.5*parent]
    
    Score --> Threshold{分数>阈值?}
    Threshold -->|No| Continue[跳过]
    Threshold -->|Yes| Collect[加入结果集]
    
    Collect --> IsLeaf{是叶子节点?}
    IsLeaf -->|Yes| Continue
    IsLeaf -->|No| Push[目录加入队列]
    Push --> Continue
    
    Loop -->|No| Check[收敛检测]
    Check --> Stable{top-k稳定?}
    Stable -->|Yes| Return[返回结果]
    Stable -->|No| Continue
```

### 4.2 根目录映射

| context_type | 根目录 |
|--------------|--------|
| MEMORY | `viking://user/memories`, `viking://agent/memories` |
| RESOURCE | `viking://resources` |
| SKILL | `viking://agent/skills` |

### 4.3 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `SCORE_PROPAGATION_ALPHA` | 0.5 | 50% embedding + 50% parent |
| `MAX_CONVERGENCE_ROUNDS` | 3 | 收敛检测轮数 |
| `GLOBAL_SEARCH_TOPK` | 3 | 全局搜索候选数 |
| `MAX_RELATIONS` | 5 | 每资源最大关联数 |

### 4.4 分数传播算法

```python
# 核心公式
final_score = alpha * embedding_score + (1 - alpha) * parent_score

# 其中 alpha = 0.5
# 优点：平衡局部相关性和全局相关性
```

```mermaid
flowchart LR
    subgraph Score["分数计算"]
        E[embedding_score] --> Mix[混合]
        P[parent_score] --> Mix
    end
    
    Mix --> Alpha[α = 0.5]
    Alpha --> Final[final_score]
    
    style Mix fill:#f9f,color:#333
    style Final fill:#9f9,color:#333
```

## 5. Rerank 精排

### 5.1 触发条件

- 配置了 Rerank API Key
- 使用 THINKING 模式（search() 默认）

### 5.2 Rerank 流程

```mermaid
flowchart TB
    subgraph Candidates["候选集"]
        C1[结果1]
        C2[结果2]
        C3[结果N]
    end
    
    Candidates --> Batch[批量 Rerank]
    
    subgraph RerankProcess["Rerank 处理"]
        Batch --> Prompt[构建 Prompt]
        Prompt --> LLM[LLM 评分]
        LLM --> Scores[返回分数列表]
    end
    
    Scores --> Sort[按分数排序]
    Sort --> TopK[返回 top-k]
```

### 5.3 评分方式

```python
if rerank_client and mode == THINKING:
    # 使用 Rerank 模型
    scores = rerank_client.rerank_batch(query, documents)
else:
    # 使用向量分数
    scores = [r["_score"] for r in results]
```

| 后端 | 模型 |
|------|------|
| Volcengine | doubao-seed-rerank |

## 6. 检索结果

### 6.1 MatchedContext

```python
@dataclass
class MatchedContext:
    uri: str                     # 资源 URI
    context_type: ContextType    # RESOURCE/MEMORY/SKILL
    is_leaf: bool                # 是否叶子节点
    abstract: str                # L0 摘要
    score: float                # 最终分数
    relations: List[RelatedContext]  # 关联上下文
```

### 6.2 FindResult

```python
@dataclass
class FindResult:
    memories: List[MatchedContext]    # 记忆结果
    resources: List[MatchedContext]   # 资源结果
    skills: List[MatchedContext]      # 技能结果
    query_plan: Optional[QueryPlan]    # search() 时有
    query_results: Optional[List[QueryResult]]
    total: int                         # 总数
```

### 6.3 结果示例

```python
results = client.find("OAuth 认证", target_uri="viking://resources/")

# 遍历资源结果
for r in results.resources:
    print(f"URI: {r.uri}")
    print(f"Score: {r.score:.4f}")
    print(f"Abstract: {r.abstract}")
    print(f"Relations: {len(r.relations)}")

# 获取总数
print(f"Total: {results.total}")
```

## 7. 流程图

### 7.1 find() 完整流程

```mermaid
flowchart TB
    Start[find("query", target_uri)] --> Check{检查参数}
    
    Check -->|有效| Search[向量搜索]
    Check -->|无效| Error[返回错误]
    
    Search --> Filter[标量过滤]
    Filter --> TopK[取 top-k]
    TopK --> Load[加载 L0/L1]
    Load --> Score[计算分数]
    Score --> Rerank{需要 Rerank?}
    
    Rerank -->|Yes| RerankCall[Rerank API]
    Rerank -->|No| Sort[排序]
    
    RerankCall --> Sort
    Sort --> Build[构建 MatchedContext]
    Build --> Return[返回结果]
```

### 7.2 search() 完整流程

```mermaid
flowchart TB
    Start[search(query, session_info)] --> Intent[意图分析]
    
    Intent --> Types{生成类型}
    
    Types -->|skill| SkillQ[TypedQuery(SKILL)]
    Types -->|resource| ResourceQ[TypedQuery(RESOURCE)]
    Types -->|memory| MemoryQ[TypedQuery(MEMORY)]
    
    SkillQ --> Parallel[并行检索]
    ResourceQ --> Parallel
    MemoryQ --> Parallel
    
    Parallel --> Merge[结果合并]
    Merge --> Rerank[Rerank 精排]
    Rerank --> Final[最终排序]
    Final --> Return[返回结果]
```
